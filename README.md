# MOVIN Company Profile

Modern responsive company profile for a packaging company.

## Stack
- Next.js
- React + TypeScript
- Tailwind CSS
- Lucide can be added for icons later

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Deploy to Vercel
Push this folder to a GitHub repository, then import the repository into Vercel. Vercel will detect Next.js automatically.

## Before launch
Replace:
- `hello@movin.example`
- `+62 812 0000 0000`
- placeholder visual blocks in Portfolio/Home
- company address and legal information
- service descriptions with actual MOVIN offerings
- contact form with a real email/form endpoint

The visual system is intentionally simple so branding, photos, and real company content can be added without restructuring the site.
